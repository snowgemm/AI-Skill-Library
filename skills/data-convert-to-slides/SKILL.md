# Analytical Presentation Conversion

Use when converting validated analysis into PowerPoint or Google Slides for a briefing, review, or decision meeting.

## Workflow

1. Clarify audience, meeting objective, time limit, presentation format, and the decision the audience should make.
2. Select only the evidence required for the narrative. Preserve definitions, periods, filters, units, and uncertainty.
3. Create a storyline: context, question, answer, evidence, drivers, implications, and requested decision.
4. Use one main message per slide. Prefer legible charts and annotated comparisons over dense tables or long paragraphs.
5. Keep axes, denominators, units, and time periods visible. Do not crop charts in ways that change their meaning.
6. Move detailed methodology, definitions, and supporting tables into appendix slides.
7. Check slide dimensions, theme consistency, text overflow, contrast, font embedding/substitution, chart readability, and source notes.
8. Reconcile key values on slides against the validated analysis before delivery.

## Verification checklist

- Slides answer a defined question.
- Each slide has one clear message.
- Charts retain labels, units, and context.
- Text fits at presentation size.
- Key numbers reconcile with the source analysis.

## Reporting

State the source and version of data/artifacts, filters and definitions, checks performed, assumptions, unresolved limitations, and files delivered. Do not imply the host has connected data, publication, sharing, scheduling, or file-conversion capabilities unless those tools are actually available and report success.
