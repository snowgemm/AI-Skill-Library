# Codex Theme Selection

Use when a user asks to choose, compare, or troubleshoot Codex appearance/theme settings.

## Workflow

1. Identify the Codex surface involved: CLI, desktop app, or editor integration; theme options may differ.
2. Check the current version and official settings documentation before naming supported themes or config keys.
3. Ask about practical readability needs such as light/dark environment, contrast, syntax distinction, and reduced visual strain without making medical claims.
4. Preview available options using the host's supported UI or configuration mechanism.
5. Change only the requested appearance preference. Do not rewrite project files or global settings unless the user specifically asks.
6. Verify the selected theme is applied and report how to revert.

## Verification checklist

- Correct Codex surface/version is identified.
- Only documented options are offered.
- Change is scoped to appearance.
- Applied state and rollback are verified.

## Reporting

Report the scope, files/data inspected, actual tool state, changes, tests and measured results, and limitations. Do not imply an action, setting change, delegation, or cost figure exists without directly observable evidence.
